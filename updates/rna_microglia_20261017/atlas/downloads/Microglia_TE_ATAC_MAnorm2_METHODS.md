# Exploratory MAnorm2 analysis of Microglia TE-overlapping ATAC peaks

The same accepted common mm10 peak matrix used for the atlas DESeq2 analysis was reused: 335,546 nonoverlapping regions, 20 mice (four per condition, two female and two male), and 176,629 regions with any coordinate overlap with canonical mm10 RepeatMasker annotations. The matrix derives from 9,152 provisionally labeled Microglia nuclei across 104 ATAC libraries and 38,409,129 admitted fragments. No BAMs or new fragments were read for this analysis.

MAnorm2 1.2.2 analyzed 26,590 regions with at least 10 counts in at least four mice; 14,896 of these overlap a TE. Pseudo-reference MA normalization used autosomal common regions, five biological conditions and an empirical local mean-variance fit. The four pairwise tests compare each other condition to WT_3mo, and an omnibus five-group table is retained. The all-eligible-region BH q value is the primary reported FDR scope. The TE-only BH q value is provided separately. These tests use a **count-positive occupancy proxy**, not independently called per-mouse peak occupancy. Sex is balanced but is not included in the MAnorm2 model. Consequently these results are an exploratory sensitivity analysis, not a replacement for the prior sex-adjusted DESeq2 model.

TE-associated means any positive coordinate overlap between a counted peak and a TE locus. A changed whole-peak count does not isolate the TE sequence or establish TE-driven regulation. The two 5xFAD candidate peaks lie in the prior Thy1-region windows, where construct-related mapping/copy-number confounding remains possible. The APOE4/TREM2 candidate matches a previously observed DESeq2 peak. Four WT_21mo TE-overlap peaks reach all-peak q<0.05 in MAnorm2 but were absent from the prior DESeq2 TE hit list; treat this discordance as method sensitivity.

The boxplot uses one value per mouse: 100 × summed counts at TE-overlapping common peaks / summed counts at all common peaks. Fragment overlap counts are nonexclusive across regions; this is neither unique TE fragment fraction nor TE-copy-normalized enrichment. The y-axis is intentionally narrow to expose the small between-mouse differences. No hypothesis test or significance marks are attached to this descriptive plot.

The downloadable ZIP contains four complete pairwise TE-overlap peak tables, the omnibus table, summary, mouse-level boxplot source table, exact analysis script, plotting script and session details. The full R fit is retained on LiSC in the analysis directory.
