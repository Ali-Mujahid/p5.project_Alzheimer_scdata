# IRescue Microglia TE-copy differential RNA expression

## Inputs and replication
The four completed, unchanged IRescue locus-level matrices are the inputs. Only the 22,251 selected Microglia cells are included. Each target is compared with four WT_3mo mice using four target mice (two females and two males per group). Technical libraries/cells/loci are not biological replicates. The four targets are WT_6mo, WT_21mo, 5xFAD_3mo and APOE4_TREM2_3mo. Each comparison uses exactly the same TE copies in target and control. These are the previously selected target-specific ATAC-peak-bound TE sets, not a genome-wide RNA screen. Stellarscope counts are not used here.

## Model and normalization
R 4.5.2, edgeR 4.8.0, robust quasi-likelihood GLM, `legacy=FALSE`, pairwise design `~ sex + condition`, reference WT_3mo. Each design has rank 3 and five residual degrees of freedom. Positive log2FC means higher expected RNA counts in target. Fractional expected IRescue allocations are kept unchanged; no rounding, DESeq2 integer conversion, z-scoring of model inputs, cell pooling as replication, or direction-based normalization selection is used.

The primary offset is the independent gene-derived TMM effective library depth of the same selected Microglia mice, as previously computed from their raw gene counts. This estimates TE RNA relative to gene RNA depth. It does not establish absolute molecules per cell. Normalization factors, gene depths, cell numbers and exact sample order are included. A separate sensitivity model uses TMMwsp composition factors estimated from all 1,075 IRescue locus-fit subfamily sums with complete TE library totals. Those factors are not estimated from the small peak-selected subset. This sensitivity estimates relative TE composition and may remove a common shift in TE/gene RNA. Neither normalization is selected to favor disease induction.

## Filtering and multiple testing
Within each pair, edgeR `filterByExpr` uses group sizes, `min.count=5`, `min.total.count=15` and primary gene exposures. Filtering depends on abundance/replication, not an observed target-up direction. The same filter is used for both normalizations. All zero and low-expression copies stay in `all_TE_results.tsv` with NA PValue/FDR and explicit status. The original raw matrices remain intact.

BH FDR is calculated across all tested copies in each prespecified comparison. Primary significance is FDR <0.05; separate FDR <0.10 files are exploratory. No extra absolute log2FC cutoff was applied. A separate pooled-BH table across all four primary comparisons is supplied for stronger control across the four reported test families. Inference is conditional on the selected ATAC sets; peak selection in the same experimental animals and uncertain TE-copy assignment limit generalization.

## Outputs and visualizations
Each target has all-row results, FDR0.05 and exploratory FDR0.10 lists for primary and sensitivity normalization, model/axis diagnostics and normalized CPM values. Volcano plots use target/control log2FC on x and -log10 BH FDR on y. Red/blue indicate primary FDR <0.05, gold exploratory 0.05–0.10, grey other tested copies. Heatmaps use log2(1+gene-normalized CPM), scaled within each TE copy across eight mice (display only), clipped to +/-2.5; sample columns retain control females, control males, target females, target males. All FDR0.10 copies appear in the overview and up to 50 best-FDR copies in readable details. If none pass, an explicit empty-result page is shown. There is no substitution of variable nonsignificant copies as differential TEs.

The QC PCA, relative-log-expression values, library sizes, sex, cell counts, mean-difference and QL-dispersion diagnostics are retained. No mouse is automatically excluded and no biological age/genotype effect is regressed out of the model. A generated fractional-count fixture verifies API behavior and expected effect direction, not biological validity. P-values do not propagate IRescue EM assignment uncertainty. Intronic/read-through or embedded host-transcript signal cannot establish autonomous TE transcription; coordinates are fragmented RepeatMasker intervals rather than reconstructed intact insertions.

Official edgeR documentation: https://bioconductor.org/packages/edgeR/ . Fractional-count and QL methods: https://pmc.ncbi.nlm.nih.gov/articles/PMC11754124/ .
