# TE architecture figure A–I · 24 October 2026

Two study-specific figures adapt all nine components of the supplied reference image. Both are ATAC accessibility and TE-coordinate figures. They do not measure TE RNA expression.

## All annotated ATAC cell types

The older accepted cell-type calibration provides 456,472 initial ATAC nuclei, 28 calibrated cell types, and initial peak/RepeatMasker overlap. Panels A, E, G, H and I use the original equal-animal peak-base-pair overlap tables. A compares annotated mm10 TE copy counts with the *fraction of callable peak bp* covered by each TE subfamily, not the fraction of TE insertions overlapped by peaks. B uses the accepted initial native mm10 peak midpoint and canonical TE midpoint genomic-context table; these are not the newer Microglia manual peaks. C–D show the saved UMAP and 11 initial ATAC clusters, with 65,000 deterministic display points; D's names are the majority published calibration labels for visual orientation only. E and G show within-feature z scores of equal-animal family/subfamily coverage. F displays the older copy-level hypergeometric q values as an **uncalibrated exploratory sensitivity**; its null is not matched for GC or mappability and no calibrated inference is claimed. H shows descriptive chromosome-weighted genomic coverage ratios without cell-type-specific p values. I shows per-animal TE-overlapping callable peak-bp fractions; missing/noncallable groups are omitted, never set to zero. This all-cell-type analysis is an earlier calibration, not a re-call from the manual Microglia BAM peaks.

## Microglia

The newer user-supplied `global.manual.atac-peaks.with_group.bed` has 370,514 input lines. The reviewed peak procedure removed 14,893 malformed duplicate copies of correctly named records and retained **355,621** distinct per-animal called peaks from 20 mice, four per condition. The user-supplied six-column `TEs.sorted.bed` is the mm10 TE annotation. Any positive-base overlap of a complete peak interval and TE locus counts; no MACS summit is substituted. A compares reference TE copies with the mean of five condition-specific *distinct TE-copy fractions overlapped by called peaks*, using the supplied BED class and name (not assuming that its name is a fine subfamily). B uses lower midpoints of TE-positive Microglia peaks and mm10 knownGene genomic categories; it does not show the genomic context of non-TE peaks. C–D use the reviewed 9,152-cell Microglia ATAC UMAP and provisional Leiden 1.8 labels, joined to the per-cell TE table by the complete cell-ID and animal-ID axis. E averages per-cell exclusive family rates within each mouse, then the four mice equally per condition. F uses the saved animal-level family model against WT 3 mo; the dashed line marks exploratory FDR 0.1, and no point reaches it. G displays feature-wise z scores of the descriptive cluster means. H reports the maximum descriptive cluster-versus-rest family-rate ratio; no cluster-specific FDR is available. I shows per-cell TE-family fragment-rate distributions for visual QC only. Cells are not biological replicates.

The all-cell and Microglia heatmaps use different measurement units and source peak sets; compare patterns *within* each panel, not magnitudes between figures. No final cell-state annotation, novel TE insertion, autonomous TE transcription, or locus-specific differential accessibility is established by these plots. Data tables and source SHA-256s are in `TE_architecture_A_to_I_data.json`. Code used to render the figures is saved locally at `work/TE_reference_figure_20261024/build_te_figure.py`.
