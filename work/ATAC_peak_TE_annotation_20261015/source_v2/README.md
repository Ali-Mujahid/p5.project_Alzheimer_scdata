It reuses the68126 accepted common mm10 consensus peaks and467 accepted animal×published-calibration-type MACS narrowPeak files. It reads coordinates and small producer metadata only. It does not rerun MACS/counting, read gene/peak matrices, assign final cell types, or measure TE expression or fragment accessibility.

The source uses the UCSC17-column `canonical.rmsk.txt` including bin. Each native RepeatMasker row and every half-open peak×repeat overlap is retained in a long gzip table, including native repClass,repFamily,repName,strand and source-row identity. Annotated peak tables retain every original peak column and add list-valued taxonomy, hit count, blacklist/callable bases and repeat-kind union coverage. Nested/duplicate records remain in the long table; union endpoints avoid counting a base twice within a category. A peak can belong to multiple categories. Taxonomic categories overlap, so sums across classes/families/subfamilies need not sum to100%.

Taxonomy is native:repClass is class/type,repFamily is family,repName is subfamily. User 'subclass' explicitly means the native repFamily alias, not an invented new rank. Primary TE endpoint classes are DNA,LINE,LTR,RC,Retroposon,SINE. Simple_repeat,Low_complexity,Satellite and RNA-repeat labels are retained and flagged separately. Question-mark classes are uncertain, not silently merged into primary TE. All raw classes are annotated and included in class tables; primary TE family/subfamily endpoints retain full native(class,family,subfamily) context. No single best overlap or arbitrary taxonomy harmonization is used.

Coverage denominators use the union of each group's peaks after blacklist subtraction on chr1–19,X,Y. Background is union repeat coverage over the same blacklist-excluded nuclear genome, weighted by that group's callable peak-union bp on each chromosome. The fold is **descriptive chromosome coverage observed/expected**, without p-values,FDR or genotype-effect claims. GC,TSS/gene context and mappability are not matched. This does not establish statistical TE enrichment or accessibility change. Empty/noncallable groups remain present with NA fractions/folds; unproduced animal×type groups are missing, not fabricated zeros.

Every producer group corresponds to an animal, which is the biological replicate; sex,age,genotype and R1/R2 animal identity are retained. `genotype` is the animal-identifier naming token:APOE4_TREM2 corresponds to the atlas canonical APOE4/TREM2 label; it is not a different biological genotype. Conditions concatenate that token and age, so age and genotype are never collapsed. The source labels are published calibration labels, not independent final annotations. The existing rare/novel-state and pituitary peak-discovery limitations remain.

Outputs include468 annotated-peak gzip tables,468 all-hit gzip tables, full native taxonomy and animal×type/category tables, all-class and selected family/subfamily heatmaps, all28 calibration-type animal-point/boxplot pages, and additional microglia family/subfamily views. Full tables retain all categories. Family/subfamily heatmaps select top45/top65 by descriptive mean coverage plus microglia top20; display selection does not alter the tables. Missing groups/values remain NA. Extra microglia views do not remove other cell types.
