# GSE212606 mouse RNA, ATAC and TE atlas

Portable source and data snapshot for the interactive atlas, including its offline browser assets, verified reports, builder/validation scripts, provenance and third-party licenses.

The atlas is provisional. QC, final retention, normalization, final cell types and count-based TE analyses have separate evidence gates. The interface identifies unavailable results explicitly.

A complete verified package and launch instructions are being added in the next commit. This repository is the user-selected public destination: https://github.com/Ali-Mujahid/p5.project_Alzheimer_scdata.
