## Execution order and evidence gates

1. **Full-study QC and doublet array**, one task per RNA or ATAC PCR library, up to 16 concurrent. RNA reuses all original per-library gene matrices and saved pre-Scrublet metadata so new doublet assessment is not restricted to the old singlets. ATAC reuses accepted peak counts and alignment-derived per-nucleus QC. Recompute counts/genes/RNA mitochondrial percentage; retain original source metrics. Reconcile cell IDs, raw integer counts, animal/sex/condition and library IDs. Empty/very low-complexity barcodes fail source and count support. EasySci is combinatorial indexing; do not run droplet emptyDrops without a validated ambient-barcode model.
2. **Filtering and retention review**: preserve every score/reason. For RNA, conservative low-count/low-gene outliers use log1p values and a lower 3 scaled-MAD boundary per technical library; mitochondrial outliers use a higher 3 scaled-MAD boundary, with undefined zero-spread thresholds left unresolved. Large-count cells are review signals, not automatic doublets. scDblFinder is run per PCR × RT/donor-barcode collision partition inside each library task with explicit 2%, 5% and 10% rate sensitivities because a 10x cells-per-thousand default does not describe EasySci. Concordant calls define the conservative doublet exclusion; discordant calls remain flagged. ATAC uses correlated-peak aggregation. Partitions with fewer than 100 supported nuclei retain an unresolved call and are not automatically excluded. Simulated doublets never mix incompatible RT/donor barcodes. RNA source Scrublet is a comparator, not an additional automatic intersection. ATAC mitochondrial fraction is mitochondrial query groups / all classified query groups, not mitochondrial gene activity. ATAC low/zero peak counts are review signals, not empty-nucleus exclusions: a rare cell type may lack discovery-peak representation while retaining strong nuclear-fragment/TSS support. Such cells remain with unresolved peak-model doublet status until peak refinement. FRiP/nucleosome/ambient signals are reviewed without inventing a global cutoff. Reconcile exclusions by animal, condition, library and provisional lineage before downstream adoption. Every type remains eligible; report any loss of rare groups.
3. **RNA SCTransform v2 → PCA → PCR Harmony → neighbors/Leiden/UMAP**, after the retained-cell manifest. Fit by technical library using raw UMI counts, retain models and original counts, limit residual features and project in blocks to avoid dense 2.3M×55k matrices. Actual R/runtime versions and memory measurements gate production. SCTransform corrected counts/residuals are distinct from original integer UMIs. PCR correction must pass overlap/confounding gates. Genotype, age and sex are never batch-removal variables. Produce same-feature/PC uncorrected controls.
4. **ATAC retained-cell TF-IDF/LSI → PCR Harmony → neighbors/Leiden/UMAP**. SCTransform is not applied to accessibility counts. Compare corrected/uncorrected graphs and depth correlations. Review refined cell-group/animal peak support, update common consensus and FRiP as needed; retain initial universe as a sensitivity comparison.
5. **Annotation and labels**, all types: genome-wide ranked markers plus 10–20 canonical positive/negative markers per type; per-cell marker breadth, animal support, QC, doublet/ambient sensitivity and atlas calibration. Coarse-to-fine labels with confidence and unknown/mixed categories. Additional microglia state review distinguishes homeostatic, reactive/DAM-associated, interferon and cycling programs from macrophages, vascular signal and mixed cells without forcing every cell into one program. Microglia is an extra view, not the whole atlas.
6. **RNA-to-ATAC label transfer**: reviewed RNA labels and shared genes/gene activity, anchors/transfer scores, confidence calibration by held-out animals and independent ATAC marker/peak support. Leave low-confidence cells unknown; keep independent ATAC clusters. Harmony alone does not transfer identities or make assays barcode paired.
7. **Animal pseudobulk gene/peak/TE analysis**: raw uncorrected counts summed within animal×reviewed cluster/cell type; technical libraries merged, sample counts and library sizes explicit. Primary disease contrasts: 5xFAD_3mo vs WT_3mo and APOE4_TREM2_3mo vs WT_3mo, separately. WT_6mo/WT_21mo vs WT_3mo are separate aging contrasts. Use sex-adjusted edgeR quasi-likelihood or DESeq2 designs after rank/replication checks, FDR/effect sizes and sensitivity to cell representation. No pooling old WT controls with young disease mice. Across-cell-type differences are descriptive or use paired-animal models; cells are not biological replicates. Minimum pseudobulk representation is declared from observed distributions, with missing/untestable comparisons shown rather than filled with zero evidence.
8. **RNA TE expression**, full preserved multimapping queryname BAMs on VSC, barcode/UMI-aware deduplication and explicit multimapper allocation. Family/subfamily primary, locus results only where identifiable; unique-only sensitivity; host-gene/intronic/exonic overlap, mappability and annotation checks. Preserve the STAR 100-placement ceiling. Export raw cell×TE and animal pseudobulks, TE embeddings/overlays, dotplots and differential tables. An old single-pool TE experiment is not the study result.
9. **ATAC TE accessibility**, all 104 fragment pools with final retained-cell manifest and RepeatMasker coordinates: fragment-vs-Tn5 definitions declared, each fragment counted once per feature, overlapping annotation rules explicit. Produce cell×TE and animal pseudobulks, TE-associated peak annotations, background/mappability sensitivity, disease differential accessibility, locus/cell-type/genotype signal tracks. Accessibility is not TE RNA expression. TE family-level signal does not imply an independently transcribed individual insertion.
10. **Local HTML atlas** with all types, assay/cluster/type/animal/genotype selectors, all-mice or combined-condition UMAPs, marker overlays and 10–20 ranked/canonical markers per supported type, selectable palettes and clearly named raw/log-normalized/scaled/z-score views. Cluster renaming/merging is an editable display mapping with export/import and provenance, never a silent raw-data rewrite. Dotplot builder, per-animal boxplots with points, RNA/ATAC/TE views, TSS/TES/gene-body/TE coverage and genotype tracks. Large arrays are lazy loaded or summarized for browser use; missing results remain visibly unavailable. Additional microglia landing view. Export PDF figures and TSV/JSON data with exact filters.
